# Roadmap

1. **0.1, starter (incluído):** demo web, dados fictícios, handshake e HMAC, testes e estrutura Flutter.
2. **0.2, núcleo seguro:** NestJS/PostgreSQL, tenants, autenticação, RBAC, migrations, testes.
3. **0.3, Meta:** Embedded Signup, onboarding de telefones, webhooks persistentes e processamento idempotente.
4. **0.4, conversas:** caixa de entrada real, envio de texto, regras de templates e janela de atendimento.
5. **0.5, aplicativos:** integração Flutter, login, notificações e distribuição para testes.
6. **1.0, MVP piloto:** auditoria, backups, observabilidade, LGPD, testes E2E e validação com clientes.

Nenhuma data de conclusão ou aprovação da Meta é garantida.
