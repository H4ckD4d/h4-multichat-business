# Aplicativo Flutter demonstrativo

`lib/main.dart` contém uma interface local, com contatos fictícios. **Ainda não conecta o backend**.

É necessário ter o Flutter SDK instalado. Para criar os diretórios de plataformas com os templates da versão instalada do Flutter, executar nesta pasta:

```bash
flutter create --project-name h4_multichat_business --platforms=android,ios,macos .
flutter pub get
flutter run
```

O build para iOS/macOS requer um Mac com Xcode compatível. A compatibilidade de versões do Flutter, macOS e Xcode deve ser verificada na documentação atual.
